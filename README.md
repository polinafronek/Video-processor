# Обработчик пересветов и провалов
Программа для анализа и обработки видео с выделением пересветов и провалов 

## Функционал 
- **Анализ яркости** - определение пересвеченных и темных областей в каждом кадре
- **Визуализация "зеброй"** - анимированное штрихование проблемных зон
- **График анализа** - отображение динамики яркости видео
- **Настройка порогов** - регулировка чувствительности для светлых и темных областей
- **Выбор типа проблем** - можно выделять только пересвеченные, только темные или обе проблемы

## Запуск программы

### Требования:
- Установленный Docker
- 4-8 GB оперативной памяти в настройках Docker

### Запуск:
- Клонирование репозитория командой: git clone https://git.miem.hse.ru/kg25-26/pafronek.git
- docker-compose up

## Эксплуатация: 
- Приложение доступно по адресу: http://localhost:8080
- Требуется выбрать видео для обрабоки
- Можно настроить желаемые пороги для провалов и пересветов, а также выбрать, какой из типов проблем в видео вы желаете отображать: пересветы/провалы/оба режима
- Нажать кнопку 'Process Video' и подождать несколько минут, пока он обработается

## Частые проблемы 

1. #### В некоторых браузерах недоступен предпросмотр, но весь остальной функционал доступен

##### Браузеры для macOS:
✅ **Рекомендуется:** Safari  
✅ **Рекомендуется:** Яндекс.Браузер  
❌ **Не рекомендуется:** Chrome
❌ **Не рекомендуется:** FireFox

##### Браузеры для Windows:
✅ **Рекомендуется:** Яндекс.Браузер  
❌ **Не рекомендуется:** Chrome
❌ **Не рекомендуется:** FireFox

##### Причина: 
Docker создает видео с кодеками, которые не все браузеры могут воспроизводить напрямую. То есть из-за конфликтов кодеков Docker и браузеров таких, как Chrome и Firefox, не воспроизводится предпросмотр, при этом все остальные функции работают исправно. Safari и Яндекс.Браузер являются более надежными, при их использовании весь функционал в распоряжении пользователя, в том числе предпросмотр. 

2. #### Порт занят системно. 
В таком случае следует запустить программу на другом порте, например, на 5000/5001/8000. Замену нужно произвести в трех файлах: app.py, Dockerfile, docker-compose.yml
